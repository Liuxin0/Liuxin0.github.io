# Liuxin0 Research Demonstrations

GitHub Pages site for interactive research demonstrations.

- [`hwb-plus/`](hwb-plus/) contains four-way VCTK comparisons: LR input, HWB, HWB-Plus, and HR reference, each with a paired spectrogram.

`tools/build_hwb_comparison.py` splits the supplied three-channel LR/HWB-Plus/HR material and combines it with the exported HWB baseline predictions.
