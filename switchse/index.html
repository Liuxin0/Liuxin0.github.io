Listening comparison

One model, two target-domain operating modes

Each row fixes one utterance and compares the noisy input, the pre-trained GCRN baseline where applicable, and SwitchSE in both operating modes. S_Enh prioritizes enhanced speech quality; S_ASR is optimized for recognition-friendly output.

Playback note Within each utterance, all conditions share one peak gain with a maximum of -1 dBFS. This is playback normalization only: relative amplitude differences between conditions in the same row are preserved. Spectrograms use the AudioLens Rose palette and its default display brightness.
